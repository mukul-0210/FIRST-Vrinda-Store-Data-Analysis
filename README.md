# FIRST-Vrinda-Store-Data-Analysis
Vrinda Store Sales Analysis: Analyzed 31,000+ orders (₹2.11 Cr+ revenue) using MS Excel. Key finding: Adult women (30–49) buying ethnic wear (Kurtas &amp; Sets) drive 64% of sales. Amazon, Myntra, and Flipkart generate 75%+ of order volume, with peak demand in Maharashtra and Karnataka. Interactive dashboard built with Pivot Tables &amp; Slicers.
